# MRI Deepfake Detection System 🧠

An advanced deep learning system for detecting GAN-generated synthetic MRI brain scans using custom CNN architecture and intelligent preprocessing pipeline.

## 🎯 Project Overview

This project implements a complete end-to-end deepfake detection system for medical imaging, specifically targeting synthetic MRI scans generated by adversarial networks. The system achieves ~99-100% detection accuracy through custom feature extraction and spatial domain analysis.

## ✨ Key Features

- **Intelligent Preprocessing**: Automatic geometric correction and standardization to 256×256 resolution
- **Dual-Pathway Routing**: Intensity-based filtering (T1 Dark vs FLAIR Bright sequences)
- **Spatial Classification**: ResNet-18 based orientation detection (Axial/Coronal/Sagittal)
- **Custom DCGAN**: Generates 2,000+ synthetic deepfake MRIs for dataset augmentation
- **Dual Detection Models**: DenseNet-121 baseline + Custom 4-layer CNN detector
- **Real-time Web Interface**: Gradio-based UI for clinical simulation
- **Twin Generation**: Instantly generates synthetic counterpart of uploaded scans

## 🏗️ System Architecture

### Phase 1: Data Ingestion & Preprocessing
- **Geometric Correction**: 90° clockwise rotation for standardized anatomical position
- **Standardization**: Strict 256×256 pixel resolution with padding
- **Background Removal**: Automatic cropping for consistent input

### Phase 2: Algorithmic Routing
- **Intensity Filtering**: 
  - Mean brightness < 65 → T1 Dark pathway
  - Mean brightness ≥ 65 → FLAIR Bright pathway
- **Orientation Classification**: ResNet-18 identifies Axial/Coronal/Sagittal planes

### Phase 3: GAN Synthesis
- **Architecture**: Custom DCGANs optimized for 256×256 medical imaging
- **Dual Models**: Separate generators for T1 Dark and FLAIR Bright sequences
- **Output**: 2,000+ highly realistic synthetic deepfake MRIs

### Phase 4: Detection Models
- **Baseline**: DenseNet-121 transfer learning (100% validation accuracy)
- **Primary Detector**: Custom 4-layer CNN with:
  - Max Pooling layers
  - ReLU activation
  - 50% Dropout regularization
  - Spatial domain feature extraction
- **Detection Method**: Identifies GAN "checkerboard" artifacts

### Phase 5: Deployment
- **Interface**: Gradio web application
- **Real-time Analysis**: Instant REAL/FAKE verdict
- **Twin Generation**: Synthetic counterpart visualization

## 💻 Usage

### Web Interface (Recommended)

1. Launch the Gradio app: `python app.py`
2. Upload an MRI brain scan (256×256 recommended)
3. View results:
   - **Authenticity Verdict**: REAL or FAKE with confidence score
   - **Synthetic Twin**: GAN-generated counterpart
   - **Metadata**: Sequence type and orientation

### Command Line Interface

**Detect deepfakes:**
```bash
python src/inference/detect_forgery.py --input path/to/mri.jpg
```

**Generate synthetic MRIs:**
```bash
python src/inference/generate_twins.py --sequence bright --count 100
```

**Preprocess images:**
```bash
python src/preprocessing/standardize.py --input raw_mri/ --output processed_256/
```

## 🔬 Technical Details

### Custom CNN Architecture
Input: 256×256×1 grayscale MRI
├── Conv2D (32 filters, 3×3) + ReLU + MaxPool
├── Conv2D (64 filters, 3×3) + ReLU + MaxPool
├── Conv2D (128 filters, 3×3) + ReLU + MaxPool
├── Conv2D (256 filters, 3×3) + ReLU + MaxPool
├── Flatten
├── Dense (512) + ReLU + Dropout (0.5)
├── Dense (256) + ReLU + Dropout (0.5)
└── Dense (2) + Softmax
Output: [REAL, FAKE] probability

### DCGAN Architecture
- **Generator**: 5 transpose convolution layers with batch normalization
- **Discriminator**: 5 convolution layers with leaky ReLU and dropout
- **Latent Vector**: 100-dimensional noise input
- **Output Resolution**: 256×256×1

### Detection Accuracy
- **Custom CNN**: 99.8% validation accuracy
- **DenseNet-121 Baseline**: 100% validation accuracy
- **False Positive Rate**: < 0.2%
- **Processing Time**: ~0.3 seconds per image

## 📊 Dataset

The system was trained on:

- **Synthetic MRIs**: 2,000+ GAN-generated deepfakes
- **Sequences**: T1-weighted (Dark) and FLAIR (Bright)
- **Orientations**: Axial, Coronal, Sagittal planes
